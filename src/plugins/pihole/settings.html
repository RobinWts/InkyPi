Pi-hole Version & Configuration Notes

Version Requirement: This plugin requires Pi-hole v6 or later. It uses the modern REST API (/api/*) and does not support older token-based APIs.

Authentication: If your Pi-hole has no password set, this plugin can query the API without authentication. If your Pi-hole is password protected, set PIHOLE_PASSWORD=your_password_or_app_password via the API Keys page in the web UI or in your .env file.

Self-Signed Certificates: Pi-hole v6+ automatically creates self-signed SSL certificates. If you're using HTTPS and getting SSL errors, enable "Allow insecure HTTPS" below. This only affects certificate verification, not encryption.

Enable this if your Pi-hole uses HTTPS with a self-signed certificate. This disables SSL certificate verification but keeps encryption enabled.
